## Run MongoDB With Docker Compose

1. Start MongoDB:

	docker compose up -d mongo

2. (Optional) create .env from .env.example and set MONGO_URI.

3. Start app:

	npm start

Default MONGO_URI:

mongodb://localhost:27017/NNPTUD-S2
